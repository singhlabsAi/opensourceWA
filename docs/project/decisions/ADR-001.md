# ADR-001 — Modular WCRM-Based Hybrid Agent
Status: Accepted as initial design direction, pending source audit.

## Decision
Use upstream WCRM as communication/CRM foundation; extend with a modular event adapter, conversation router, deterministic workflow runtime, AI intent/FAQ layer and server-authorized business tool gateway. Prefer extension points over rewriting WCRM internals. Use one shared conversation entry point for customers and business staff, with separate verified roles and branch scopes.

## Why
Supports button trees plus natural-language interruptions; preserves upstream updateability; enables future POS/MCP integrations; reduces risk of AI authorization bypass; keeps product reusable beyond three branches.

## Tradeoffs
More services/interfaces and operational complexity; existing WCRM workflow support must be audited to avoid duplicating capabilities. Initial MVP should minimize separate infrastructure while retaining clear module boundaries.

## Reconsider when
Source audit reveals native equivalents, integration constraints, or deployment costs that warrant a simpler implementation. Record changes in a new ADR rather than silently overwriting this decision.
