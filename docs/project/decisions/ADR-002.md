# ADR-002 — Initial Infrastructure Choices
Status: Accepted 2026-10-22

## Decision
- Database/auth/storage: hosted Supabase **free tier** (no self-hosted Postgres on the VPS for now).
- App: Docker container on the user's VPS, deployed over SSH from GitHub Actions.
- Secrets (SSH key, host, Supabase keys, ENCRYPTION_KEY, META_APP_SECRET) are kept only in GitHub environment secrets and never in the repo.
- Domain/HTTPS and the WhatsApp test number are deferred; Phase 3 can proceed without a public HTTPS domain only for internal smoke tests.

## Known risks of the free tier
- Projects pause after about 1 week without activity, and there are no automated backups or point-in-time recovery (PITR). Phase 3 must add a scheduled `pg_dump` to off-site storage plus a restore drill.
- Low limits on database size, storage and egress. Revisit before production with real customers.

## Reconsider when
Real customer traffic or PII volume grows, backups/PITR are needed, or limits are hit → move to Supabase Pro or self-host.
